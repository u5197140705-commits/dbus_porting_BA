# FRDM-RW612 Flexcomm 1 SPI Pinmux Details

These details are sourced from the FRDM-RW612 datasheet for Flexcomm 1 SPI communication.

- **FC1_CTS_SDA_SSELN0_SPI**: Flexcomm 1, L5 24 F12 GPIO[6] VIO_1 (Chip Select / SSELN0)
- **FC1_SCK_SPI**: Flexcomm 1 SPI clock, L9 21 F10 GPIO[7] VIO_1 (SPI Clock)
- **FC1_TXD_SCL_MISO_WS_SPI**: Flexcomm 1, M6 22 E10 GPIO[8] VIO_1 (MISO - Master In, Slave Out)
- **FC1_RXD_SDA_MOSI_DATA_SPI**: Flexcomm 1 SPI controller out/target in, M4 25 G10 GPIO[9] VIO_1 (MOSI - Master Out, Slave In)
